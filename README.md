# Pokedex-Javascript-htmll
Uma Pokedex moderna feita com JavaScript (ES6 Modules), CSS e HTML para fins de estudo.
Atualmente na versão **3.0**.

## Novidades da v3.0:
- **Arquitetura Modular:** Código totalmente reescrito e separado em módulos lógicos (API, UI, Estado, Utilitários), facilitando manutenção.
- **Busca Inteligente:** Sistema de autocomplete dinâmico que sugere nomes de Pokémons enquanto você digita.
- **Áudio Integrado:** Gritos (cries) puxados diretamente da base online da PokéAPI, evitando falhas de arquivos locais.
- **Visual Aprimorado:** Correções nas caixas de texto que estavam cortadas, melhorias na interface e sprites clássicos transparentes corrigidos.

---

English
A modern Pokedex made in JavaScript (ES6 Modules), CSS, and HTML for study purposes. 
Currently at version **3.0**.

## What's new in v3.0:
- **Modular Architecture:** Code fully rewritten and split into modules for better maintainability.
- **Smart Search:** Autocomplete suggestions as you type.
- **Integrated Audio:** Sounds fetched directly from PokéAPI.
- **Enhanced Visuals:** Layout fixes, transparent sprites, and visual improvements in classic mode.
